Chapter 1

Read this first

By the end of this guide, you'll have your own bot that:

  • checks your chosen stocks, ETFs, crypto and currencies every day, automatically;
  • sends you a daily summary on Telegram;
  • sends a "Time to BUY" or "Time to SELL" alert when a signal changes, including the exact price that would flip it back;
  • can backtest itself, replaying years of history to show how the rules would have done.

It runs on GitHub's free servers, so your phone doesn't need to be on, you don't need a computer running, and there's no monthly fee.

Chapter 2

How the signals work

The 200-day average

Take the closing prices of the last 200 trading days (about 10 months) and average them. You get one smooth line that shows the long-term trend.

  • Price above the line → the long-term trend is up.
  • Price below the line → the long-term trend is down.

The rule the bot follows

200-day trend rule (with 3% buffer) 🟢 BUY when the price closes above its 200-day average.
🔴 SELL when the price closes more than 3% below its 200-day average.

Why the 3% buffer? Without it, prices that hover around the line trigger BUY, SELL, BUY, SELL every few days ("whipsaws"), and each trade costs you fees. The buffer means the bot only sells when the trend has clearly broken. In testing, it cut trades from about 7 a year to about 2–3 and improved results.

Why daily closes?

The bot only looks at finished daily candles. Prices wiggle all day, and a signal based on the unfinished day could flip back by the close. Waiting for the close keeps alerts calm and reliable.

What an alert looks like

Your bot
🟢 Time to BUY Apple (AAPL)
Consider buying at around 356.27

Why:
• Price is 18.5% above its 200-day average (300.77)
• Sell trigger: a daily close below 291.75

Based on the 2026-11-13 daily close · strategy: 200-day trend rule (3% buffer).
Not financial advice. Do your own checks before trading.

The trigger line is the most useful part: it tells you exactly which price would flip the signal.

Chapter 4

Create your Telegram bot

Telegram lets anyone create a bot for free by chatting with an official bot called BotFather.

1
In Telegram, search for @BotFather (with a blue tick) and open it. Tap Start.
2
Send /newbot.
3
Type a name for your bot, e.g. My Trading Alerts.
4
Type a username ending in bot, e.g. mytradingalerts123_bot. It must be unique, so add numbers if it's taken.
5
BotFather replies with your token, which looks like 1234567890:AAEexampleXyZ1aB2cD3eF4gH5iJ6kL7m. Copy all of it: the numbers, the colon, and everything after it.
Keep your token secretAnyone with the token can control your bot. Don't paste it into chats, screenshots or forums. It only goes into GitHub (Chapter 6). If you ever share it by accident, send /revoke to BotFather to get a new one.

Get your chat ID

Your bot needs to know who to message. That's your personal chat ID.

1
Search for @userinfobot, open it and send any message.
2
It replies with your details. Copy the number after Id, e.g. 123456789.
Common mistakeThe number at the start of your bot's token is the bot's ID, not yours. If you use it, Telegram refuses with "the bot can't send messages to the bot".

Say hi to your bot

1
Open your new bot (BotFather gave you a link like t.me/mytradingalerts123_bot) and tap Start, or just send "hi".
Your bot won't reply, and that's normalIt isn't a chat bot. Messaging it once simply gives it permission to message you.
Chapter 5

Put the bot on GitHub

5.1 Create a private repository

A "repository" (repo) is just a folder on GitHub.

1
On github.com, tap + (top right) → New repository.
2
Name it, e.g. trading-bot.
3
Choose Private. Leave everything else as it is and tap Create repository.

5.2 Unzip the kit

  • Computer: double-click Trading-Bot-Kit.zip.
  • iPad/iPhone: save the ZIP to the Files app and tap it once. It unzips into a Trading-Bot-Kit folder.

5.3 Upload the files

1
On your new, empty repository page, tap the link uploading an existing file. On a repo that already has files, use Add file → Upload files.
2
Select every file in the Trading-Bot-Kit folder except the workflows folder.
Computer: drag the files onto the page.
iPad: tap choose your files → Browse → open the Trading-Bot-Kit folder → Select → tap each file → Open.
3
Scroll down and tap Commit changes. That's GitHub's word for "save".

You should now see about 14 files, such as main.py, config.yaml and strategies.py.

5.4 Add the "workflows" (the bot's schedule)

Workflows tell GitHub when and how to run the bot. They must live in a special folder, .github/workflows, so you create them by pasting.

1
In the kit, open workflows/1-signals.yml.txt. On iPad, tap it in Files to preview it. Select all of the text and copy it.
2
On GitHub, tap Add file → Create new file.
3
In the name box, type exactly: .github/workflows/signals.yml
The slashes automatically create the folders. Don't forget the dot at the start.
4
Paste the text into the big box and tap Commit changes (twice).
5
Repeat for the other three files:
Kit fileName to type in GitHub
1-signals.yml.txt.github/workflows/signals.ymlRequired
2-check-setup.yml.txt.github/workflows/check-setup.ymlRequired
3-backtest.yml.txt.github/workflows/backtest.ymlRecommended
4-compare.yml.txt.github/workflows/compare.ymlOptional
Spaces matter in these filesAlways copy from the kit's .txt files, never by retyping. If GitHub shows a red error about the file when you commit, delete the file and paste it again.
Chapter 6

Connect Telegram to GitHub

Your token and chat ID go into GitHub secrets. They're encrypted, and nobody can see them after you save them, not even you.

1
In your repository, open Settings (top tabs) → Secrets and variables → Actions.
Can't see it on iPad? Use Request Desktop Website, or go straight to github.com/YOUR-NAME/trading-bot/settings/secrets/actions
2
Tap New repository secret. For the Name, type TELEGRAM_BOT_TOKEN. For the Secret, paste your whole token. Tap Add secret.
3
Tap New repository secret again. For the Name, type TELEGRAM_CHAT_ID. For the Secret, paste your Id number (digits only). Tap Add secret.
Check the spelling of the namesThey must be exactly TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID: capital letters, underscores, no spaces. One wrong letter and the bot can't find them.

Change the alert time

In .github/workflows/signals.yml, find cron: "37 5 * * *". The two numbers are the minute and the hour, in UTC. For 07:15 UTC, use "15 7 * * *".

GitHub sometimes starts scheduled runs 10–30 minutes late when it's busy.

Chapter 9

Backtesting

A backtest replays a strategy over past prices to see how it would have done. It's the closest thing you'll get to a test drive.

Run one

1
Go to Actions → Backtest → Run workflow.
2
Choose a period (10 years is a good start) and a strategy, and optionally type some symbols. Then run it.
Your bot
🧪 Backtest: last 10y · 200-day trend rule (3% buffer)

Apple (AAPL) (2017–2026, 9.2 yrs)
$1,000 following signals → $5,608
$1,000 buy & hold → $9,379
Worst drop: signals −36% vs hold −39%
56% of 9 trades made money · invested 82% of the time
❌ Buy & hold did better

This is a real result, run on 15 Nov 2026. Apple rose strongly for most of this period, so buy & hold won. Trend rules usually earn their keep in long crashes, like 2008, rather than in strong bull runs.

How to read it

  • Final value: what $1,000 would have grown to, after a 0.1% fee per trade.
  • Worst drop: the biggest fall from a peak. Ask yourself honestly whether you'd have held on through it.
  • Trades that made money: trend rules often win less than half their trades, but the winners are bigger than the losers.

Don't fool yourself

The trap: "curve fitting"If you try enough settings, one will look amazing on the past just by luck. It usually fails afterwards.

The Compare strategies workflow avoids this trap. It picks strategies using older data (before 2021), then checks them on newer data they never saw. A strategy is only worth trusting if it holds up on both. That's how the bot's default was chosen (Chapter 1).

Results are shown in the run's Summary page on GitHub: open the Actions tab, tap the run, and scroll down.

Chapter 10

Using signals sensibly

1. Paper trade first

Most broker and charting apps (for example TradingView) offer a paper trading account that uses pretend money. Follow the signals there for 2–3 months before risking real money.

2. Decide your exit before you enter

Every BUY alert shows a sell trigger. You can also set a stop-loss (SL) order with your broker, which sells automatically if the price falls to a level you choose. It protects you against sudden crashes between daily checks.

3. Size your positions

  • Don't put everything into one symbol.
  • A common rule: risk no more than 1–2% of your account on any one trade. Risk means the distance from your buy price to your stop.

4. Know your order types

OrderWhat it does
MarketBuys or sells now, at the current price
Buy limitBuys only if the price falls to your limit or lower. It may never fill.
Stop-loss (SL)Sells automatically if the price falls to your stop
Take-profit (TP)Sells automatically when the price reaches your target

5. Market hours

US stocks trade Monday–Friday, 9:30–16:00 New York time. Crypto trades 24/7, and forex 24/5. An order placed at a weekend waits until the market opens.

Avoid: borrowing to trade; leverage you don't understand; "guaranteed profit" groups (including anyone selling signals from this bot, which the licence forbids).
Chapter 11

Troubleshooting

First, open the Actions tab, tap the failed run (❌), then tap the red step to read the error.

What you seeFix
"TELEGRAM_BOT_TOKEN and/or TELEGRAM_CHAT_ID secret is missing or empty"A secret is missing or misspelled. Go to Settings → Secrets and variables → Actions and check both names exactly (Chapter 6).
"Forbidden: the bot can't send messages to the bot"You used the bot's ID as your chat ID. Get your Id from @userinfobot and update TELEGRAM_CHAT_ID.
"Forbidden: bot was blocked by the user" or "chat not found"Open your bot in Telegram, tap Start or send "hi", then run again.
"Unauthorized" (401)The token is wrong or was revoked. Paste the whole current token from BotFather into TELEGRAM_BOT_TOKEN.
"Connection reset" / network errorA temporary glitch. The bot retries automatically; just run it again.
"No data returned for XYZ"Wrong symbol. Check it on finance.yahoo.com (Chapter 8).
Workflow missing from the Actions tabThe workflow file is in the wrong place. It must be exactly .github/workflows/name.yml, with the dot (Chapter 5.4).
"Invalid workflow file"The spacing got changed. Delete the file and paste it again from the kit's .txt file.
The bot doesn't reply to my messagesThat's normal. It only sends alerts.
No message todayNothing changed, or GitHub is running late. Scheduled runs can be delayed by up to 30 minutes.
Scheduled runs stopped after a few weeksGitHub pauses schedules in repos with no activity for 60 days. Open Actions → Trading signals → Enable workflow.
Shared your token by accident?Send /revoke to @BotFather, choose your bot, and paste the new token into the TELEGRAM_BOT_TOKEN secret.
Chapter 12

Glossary

200-day average (SMA)The average closing price over the last 200 trading days. It shows the long-term trend.
BacktestTesting a strategy on past prices
Buy & holdBuying once and never selling. The benchmark to beat.
Candle / daily closeOne day's price data; the close is the last price of the day
DrawdownA fall from a previous peak, e.g. −38%
Golden / death crossWhen the 50-day average crosses above (golden) or below (death) the 200-day
Repository (repo)A project folder on GitHub
SecretAn encrypted setting on GitHub, such as your bot token
Sharpe ratioReturn per unit of risk. Higher is better.
WhipsawBeing bounced in and out by prices hovering around a signal line
WorkflowA set of instructions GitHub runs on a schedule or when you press Run
