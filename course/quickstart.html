Trading Alert Bot: setup on one page

Keep this open next to GitHub and Telegram. For the details, see the full guide (chapter numbers in brackets).

1 · Telegram (5 min) [Ch.4]

  1. Open @BotFather → /newbot → name → username ending bot
  2. Copy the token (all of it, including the part after the colon)
  3. Open @userinfobot → copy your Id number
  4. Open your new bot → send "hi"

2 · GitHub (10 min) [Ch.5]

  1. New repository → Private
  2. Upload every kit file except the workflows folder
  3. Add file → Create new file → name .github/workflows/signals.yml → paste 1-signals.yml.txt
  4. Repeat for check-setup, backtest, compare

3 · Secrets (2 min) [Ch.6]

Settings → Secrets and variables → Actions → New secret

TELEGRAM_BOT_TOKENwhole token
TELEGRAM_CHAT_IDyour Id (digits)

4 · Switch on (2 min) [Ch.7]

  1. Actions tab → enable workflows
  2. Check setup → Run workflow → wait for 🔧
  3. Trading signals → Run workflow → wait for 👋

Then it runs daily at 05:37 UTC.

Customise [Ch.8]

Edit config.yaml → ✏️ → Commit

US stockAAPL
LondonVUSA.L
JohannesburgNPN.JO
CryptoBTC-USD

Strategy: sma_trend_buffer (default). Alert time: cron line in signals.yml (UTC).

Fix it fast [Ch.11]

"can't send messages to the bot"Use YOUR Id from @userinfobot
"chat not found" / blockedSend "hi" to your bot
401 UnauthorizedPaste the whole current token
"No data returned"Wrong symbol; check Yahoo Finance
Workflow not listedPath must start .github/workflows/
Bot doesn't replyNormal. It only sends alerts.

Use it sensibly [Ch.10]

  • Paper-trade for 2–3 months first
  • Set a stop-loss on every trade
  • Risk ≤1–2% of your account per trade
  • Run the Backtest workflow before you trust a strategy

Keep your token secret

Never share it. Leaked? Send /revoke to @BotFather and update the secret.
